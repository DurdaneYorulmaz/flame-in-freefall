# 🔥 Flame in Freefall: Microgravity Combustion & Fire Safety Analytics

*Flame in Freefall* is a data-driven web application designed to analyze fire safety risks in spacecraft and visualize combustion behavior in microgravity environments.

Created by team *Şule-i Feza* for the *NASA Space Apps Challenge*, this project turns experimental data from the NASA Physical Sciences Informatics (PSI) database into an interactive analytics dashboard.

---

## 🎯 Project Purpose
On Earth, gravity causes hot gases to rise and create convection currents. However, in microgravity, flames take a spherical shape and burn differently due to diffusion. This creates serious fire safety challenges for space stations and deep-space missions.

This platform allows researchers, engineers, and space enthusiasts to easily explore *flame spread rates, temperature distributions, and extinction limits* using real experimental data.

---

## ✨ Key Features

* *Interactive Data Visualization:* Explore combustion parameters across different pressure levels, oxygen concentrations, and fuel types through dynamic charts.
* *Experimental Data Comparison:* Compare microgravity and normal-gravity (1g) combustion datasets from NASA PSI side by side.
* *User-Friendly Interface:* Presents complex scientific datasets and Excel files in a clean, fast, and easy-to-filter web dashboard.
* *Fire Safety Insights:* Helps identify critical safety limits for material selection and fire suppression strategies in space.

---

## 🛠️ Technologies Used

* *Backend & Data Processing:* Python, Flask, Pandas, NumPy
* *Data Source:* NASA Physical Sciences Informatics (PSI) Database
* *Frontend & Visualization:* HTML5, CSS3, JavaScript, Chart.js / Plotly
* *Development Tools:* Google Colab & GitHub
